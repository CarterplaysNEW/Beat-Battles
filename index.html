SUPPORTED FORMATS

    Custom event

    A custom event runs a list of normal events. In a step, type {v1} or {v2} to use the values you set when you place the event. Delay waits that many beats before the step runs.

    EventValue 1Value 2Value 3Value 4Delay

    Custom notes

    Add a note sheet from a mod, for example NOTE_assets.png with NOTE_assets.xml, plus a splash sheet if you have one. Sparrow .xml, Packer .txt and TexturePacker .json all work. Add all the files at once.

    Add files…or drag them onto this box
